# 玉転がし - ソースコード

坂から転がってくる玉を箱（自機）でキャッチするアクションゲームで、
玉の色に合わせて箱の色を変更し、正しい色の玉をキャッチするとスコアが加算されます。

本作のプレイ動画、開発環境などの詳細については、以下のポートフォリオをご覧ください。
