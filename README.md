# [玉転がし]
坂から転がってくる玉を箱（自機）でキャッチするアクションゲーム。
玉の色に合わせて箱の色を変更し、正しい色の玉をキャッチするとスコアが加算される。

## このリポジトリについて
本リポジトリはコードポートフォリオ用です。
有償アセットの再配布防止、および権利保護の観点から、Unityのプロジェクト全体ではなく **自作のスクリプトフォルダ（C#）のみ** を公開しています。
そのため、このままクローンしてビルドすることはできません。

## 見ていただきたい注目のコード
特に工夫して実装した部分は以下のスクリプトです。

* **`〇〇Manager.cs`**
  （工夫した点を1〜2行で。例：アイテムのランダムスポーンと、時間経過による難易度調整のロジックを実装しました。）
* **`〇〇Network.cs`**
  （例：RPCを活用したクライアント間の同期処理や、状態管理を行っています。）
