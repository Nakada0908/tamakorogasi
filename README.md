# [玉転がし]
坂から転がってくる玉を箱（自機）でキャッチするアクションゲーム。
玉の色に合わせて箱の色を変更し、正しい色の玉をキャッチするとスコアが加算される。

## このリポジトリについて
本リポジトリはコードポートフォリオ用です。
有償アセットの再配布防止、および権利保護の観点から、Unityのプロジェクト全体ではなく **自作のスクリプトフォルダ（C#）のみ** を公開しています。
そのため、このままクローンしてビルドすることはできません。

## コードの注目ポイント（実装の工夫）
初めてのゲーム制作として、基本的な機能の実装に加え、処理負荷を下げる工夫を行いました。該当のコードは以下のスクリプトで確認できます。

* **`Collision_Object.cs`**
  * 衝突判定時、文字列比較ではなく処理の軽い `CompareTag()` を使用して軽量化しています。
* **`ColorAndTag.cs`**
  * 色を変更する際、プレハブの生成・破棄（Instantiate / Destroy）を行うのではなく、マテリアルの変更のみで対応し、パフォーマンスの低下を防ぎました。
* **`Clone.cs`**
  * 重力、ライフ、玉の生成数やスパンなどの変数をインスペクターに公開し、シーンを複製するだけで簡単にレベルデザイン（ステージ作成）ができるように設計しました。
